# Person A visual implementation

Authority: FOLLOW-PRD.md §§4, 5.1, 5.3, 5.6, 6, 7. Existing explicit direction retained.

Studio is an Operate surface: 64 px header, 232 px concept rail, 312 px selected inspector and one dominant map. Entry is a short project task, not a marketing page. Audience is an Experience surface: the explanation itself leads; editing chrome stays out.

Near-black stage and graphite tools; warm-white type; scarlet marks focus and the primary action. Sora for editorial titles and Inter for controls/body. Font binaries and their notices ship locally. Palette and motion tokens live only in src/styles/tokens.css; raw colors in the authored diagram match those tokens.

Signature behavior: a manual selection or accepted semantic action marks the concept's scarlet focus trace and frames its reviewed composition. The world has stable home coordinates. Overview favors labels and relationships; focused compositions favor short readable explanations. A process reveals only the approved steps requested; there is no timed step sequence.

One large statement, numbered process path, sourced metric, aspect-preserved diagram and balanced comparison give the content editorial variety without turning every node into a card. The miniature map on entry is explicitly an example, with no invented PDF provenance or recent projects.

Motion is restrained: 240 ms opacity/8 px detail transitions, 280 ms interruptible automatic camera framing, instant manual navigation. Reveals stay mounted so revisiting a topic does not replay the entrance. OS reduced motion always wins; the presenter can also enable it.

At tablet widths the inspector is a drawer. On narrow screens selecting a concept gives the inspector the full auxiliary-panel allowance; a desktop guidance message makes the inspection-only contract clear. Buttons, outlined focus, a linear outline and text status provide alternatives to color and spatial navigation.
